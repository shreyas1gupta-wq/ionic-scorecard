# PRINCIPAL'S DESK — non-firm tasks (his job / general asks)
The Principal drops ad-hoc tasks here that are UNRELATED to the firm's research (office work, documents, analyses from his day job, general questions). Rules:

1. **Firewall:** work here never touches firm research books (register, pipeline, memos). It shares only WORK_LOG (one line, tagged `[PDESK]`) so spend stays visible.
2. **Flow:** Principal writes (or tells the desk to write) the ask into `INBOX.md` → desk moves it to `active/YYYYMMDD_<slug>.md` while working (brief + outputs inline or linked) → `done/` when delivered.
3. **Confidentiality default:** treat contents as Principal-private; don't reference them in firm documents, memos, or examples.
4. **Priority:** Principal's direct asks pre-empt firm work unless he says otherwise; note the interruption in SESSION_JOURNAL so the firm thread resumes cleanly.
5. Any Claude account/desk can serve this folder.

`INBOX.md` — drop new tasks at top. `active/` — in progress. `done/` — delivered (append delivery date).
