## Template fields (RESEARCH_SOP §"Hypothesis one-pager template")

**name** — STOCK_SCORECARD_750 composite (the 0–100 quantamental score) and its component pillars, as a **cross-sectional forward-return predictor** on the Nifty-750 universe.

**one-line edge** — A transparent, rule-based percentile-rank multi-factor composite (8 pillars + 2 overlay gates + a monthly regime-conditional weight tilt) ranks the Nifty-750 universe 0–100 by forward-return potential over a 3-year horizon; the hypothesis is that this rank is monotonically related to realized forward return (top-scored beats bottom-scored).

**economic WHY** (who loses money to us, and why do they keep doing it — forced / behavioral / structural?)

The composite bundles four well-documented premia, each with a distinct loser. Grounded in this repo's own `KNOWLEDGE_BASE.md` reference list (line 25):
- **Quality (ROE/ROCE, Piotroski F-score, low accruals) + Value (cheapness on P/E, P/B, EV/EBITDA):** the losing counterparty is the **extrapolating investor** who over-pays for glamour/high-growth and over-discounts cheap-but-boring names — *behavioral* overreaction/extrapolation (Fama-French value premium; Novy-Marx profitability; Piotroski; Sloan accruals). Why it persists: *structural* limits-to-arbitrage — institutional benchmark-hugging and career risk keep professional money from arbitraging the quality-junk and value-glamour spreads (Asness–Frazzini–Pedersen QMJ).
- **Momentum / Stage (Weinstein stage + 12M/24M relative strength):** the loser is the **slow-to-react investor** — news diffuses gradually and investors anchor and adjust too slowly, so past winners keep winning over intermediate horizons — *behavioral* underreaction + slow information diffusion (Jegadeesh-Titman 1993).
- **Ownership / Smart-Money Flow (sustained FII/DII/promoter accumulation):** the loser is **less-informed retail flow** that follows informed institutional accumulation with a lag — an *informational* asymmetry.

**Honest scope of this WHY (critical — the WHY justifies TESTING, it does not pre-validate this build).** The underlying factor *premia* are academically established and cited above. That earns this composite a cheap test; it does **not** validate THIS specific construction. **Untested against forward returns** (the MASTER_PLAN's own "Open risks" flags all of these): the pillar weights (18/18/15/12/12/10/8/7), the regime-tilt magnitudes (±3/±4 additive), the DCF pillar's assumptions (discount rate, terminal growth, ERP — the most assumption-heavy pillar), the sector-neutral-vs-universe-wide choices, and above all **the blend itself**. Additional live headwind: **McLean-Pontiff post-publication decay** — these are *published* factors, so the raw single-factor premia may already be partly arbitraged; the implicit bet is that the India-microstructure adaptation + the multi-factor blend + the universe/coverage expansion recover something the crowded single-factor version leaks. **cheap-test design** (candidate — Arjun/quant-head designs the real one next; this is the R&D starting proposal)

- **Pillars to test (cleanest, fully-derivable first):** [OPINION]
  - **Quality** — ROE = net profit / (equity capital + reserves); ROCE = operating profit / (equity + borrowings). Pure line-item ratios, **no** price join, **no** shares approximation → the cleanest [DATA-derived] pillar.
  - **Value** — P/E (cheap = high score). Derivable, but requires current price joined **and** shares-outstanding approximated (net-profit/EPS) → an [INFERENCE] step; test it second and label the approximation.
  - Both are computable today from the schema verified this session (per `derived_ratios.py`'s design in the MASTER_PLAN Addendum). Start with 1–2 pillars, not the full 8-pillar composite — the composite's blend/weights/tilt are exactly what's untested, so isolating a clean single pillar is the cheaper falsification.
- **Construction:** at a handful of PIT-safe historical as-of dates (`available_date <= as_of_date`, no lookahead), rank the 750-universe into **quintiles** on each pillar (sector-neutral, per spec), then measure **forward returns** over the **longest window the data can actually support without exhausting non-overlapping sample**.
- **Power constraint (flagged, not skipped).** A *true* 3-year forward test will have **very few independent (non-overlapping) windows** given this repo's documented thin pre-2020 PIT coverage (the plan itself notes "no clean pre-2020 PIT panel to train on"). If clean PIT fundamentals only reach back ~2020–21, a 3yr non-overlapping test yields perhaps **1–2 independent windows** — near-zero raw statistical power. This is a **real power constraint, not a reason to skip the test.** Per the firm's own established low-t power-aware stance (MEMORY: rank on logic + effect size + robustness; keep only lag/placebo as hard gates), the cheap test should: (a) report the quintile-spread **direction and magnitude** over whatever window(s) the data supports — and *may additionally* run shorter (e.g. 1yr) windows purely to harvest more independent samples as a **supporting** read, clearly labeled as NOT the 3yr design target; (b) make the **placebo (shuffle) gate the actual decision rule**, not the t-stat.
- **Benchmark-law reference (D-029).** At Gate-3 the decision rule is the costs-agnostic placebo below. When any *tradeable* sleeve is later derived from the score, Gate-4 must judge it against the **cap-matched AND turnover-matched random benchmark** (`datasets/derived/benchmarks_random/`), not merely an index — beating random-with-costs is the bar. The Gate-3 shuffled-score placebo is the cheaper Gate-3-appropriate cousin of that full random-basket test.

**pre-registered kill criteria** (fixed BEFORE any data is touched — 2026-07-17; this is the whole point of the exercise)

1. **Primary bar (direction):** the quintile spread must be **monotonic and positive** — the top-scored quintile beats the bottom-scored quintile in forward return — on whichever forward window the data actually supports. A flat or inverted spread (top ≤ bottom) fails the primary bar.
2. **Hard gate (placebo):** the real score's quintile spread must **beat a placebo built from RANDOMLY shuffled scores** over the same universe and the same as-of dates (same construction, same costs-agnostic comparison). If the real spread does **not** clear the shuffled-score placebo's distribution, that is a **KILL regardless of t-stat** — consistent with the firm's lag/placebo-as-hard-gate doctrine.
3. **Not an automatic kill (power-aware):** do **NOT** hard-kill on **t-stat / DSR alone** given the small expected sample (a true 3-year non-overlapping test has very few independent windows on this repo's thin pre-2020 PIT coverage). A statistically weak but **correctly-signed, placebo-clearing** result is a **RESURRECTION-ELIGIBLE / forward-test candidate** finding, **not** an automatic kill — per the firm's low-t power-aware stance (rank on effect size + logic + robustness; keep only lag/placebo as the hard gate).
