# BOARD CHARTER — monthly board meeting (Principal chairs)
Purpose: one decisions-focused meeting/month. No status theater — status lives in the pre-read pack; the meeting is for DECISIONS and accountability.

## Protocol (/board-meet skill runs it)
1. **Pre-read pack auto-assembled** (desk compiles BEFORE convening): month-end checkpoint (template below) — book states, pipeline movement, paper P&L + tracking error, AP league + token spend, kills & catches, plan-vs-actual against QUARTERLY_PLAN milestones, blockers.
2. **Reports (tight):** CIO (firm view + tail posture, 5 lines) · each FM (book: what moved, what died, what's asked, 5 lines each) · Data Officer (data health, 3 lines).
3. **Decisions-only agenda:** each item = a question the Principal (or CIO under delegation) must answer. Anything not needing a decision goes to the pack, not the agenda.
4. **Minutes filed:** `minutes/YYYY-MM_board_minutes.md` — decisions (become D-series if Principal rulings), action items with owners+dates, dissents.
5. **Next-month plan:** appended to the checkpoint — each book's 3-5 committed deliverables (these become the next month's plan-vs-actual baseline).
6. **AP settlement posting** + Analyst-of-the-Month citation.

## Month-end checkpoint template (`month_end/YYYY-MM_checkpoint.md`)
```
# Month-end checkpoint — YYYY-MM
## Plan vs actual (from QUARTERLY_PLAN milestones): table, RAG status per item
## Books: Derivatives / Equities / Fundamental — stage moves, registered-edge changes, paper P&L + TE
## Pipeline: ideas advanced/killed (with links), trials-ledger deltas
## Risk: standing-order violations (MUST be none), stress-test results, tail events
## Data: freshness/coverage changes, new sources gated, catalog corrections
## People: AP league movement, catches, coaching notes, PIP status
## Spend: tokens by desk/agent (from WORK_LOG), efficiency trend
## Blockers & asks to Principal
## NEXT MONTH: 3-5 committed deliverables per book (the new baseline)
```
Quarterly boards additionally review: the binding plan refresh, /review-team output, process red-team findings.
